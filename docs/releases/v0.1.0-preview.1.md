The first public preview of Sandhill, a fast native Mac IDE for R and
Python bioinformatics. It is early software: expect rough edges, and please
[report what goes wrong](https://github.com/dotblot/sandhill/issues/new/choose).

## Install

Download `Sandhill-0.1.0-preview.1-macos-arm64.dmg` below, open it and drag
Sandhill to Applications. It needs a Mac with Apple silicon (M1 or newer).

Sandhill isn't signed with an Apple developer certificate, so the first time
macOS says it can't check it. Open **System Settings → Privacy & Security**,
scroll down and click **Open Anyway** beside Sandhill, or run once:

```sh
xattr -dr com.apple.quarantine /Applications/Sandhill.app
```

You also need Jupyter kernels: `ipykernel` in your Python environments, and
for R, Ark or IRkernel. See the [README](https://github.com/dotblot/sandhill#get-sandhill).

## What's in it

- Jupyter notebooks, Quarto and R Markdown documents, and R and Python
  scripts, with live R and Python sessions, Variables, a Data Explorer for
  very wide tables, Plots, Help, Packages, Git, a Terminal and Jobs.
- Projects on the Mac or on a Linux server over ssh; sessions and jobs keep
  running when you close the laptop, and their output is there when you
  come back.
- Claude Code and Codex in the AI pane, working in your live sessions
  through Sandhill's tools, with your own Claude or ChatGPT plan.
- Code that asks a question (R's `browser()`, Python's `input()`,
  `breakpoint()`, `%debug`) is answered in the Console.

## Known limits

- Mac app for Apple silicon only; servers run 64-bit Linux, tested on
  Ubuntu 24.04.
- Only Claude Code and Codex are offered as agents for now.
- No automatic updates: new versions appear on the Releases page.
- Scrolling a very large notebook can drop an occasional frame.

The SHA-256 of the disk image is in the `.sha256` file beside it.
