# 把 OpenScience 接进 AI 面板

状态：Huan 于 2026-11-11 批准并选定图标（Synthetic Sciences 标志），同日实施完成并用真的 OpenScience 做了一次完整试用。实施中发现：OpenScience 不使用通过 ACP 传入的 MCP，并且把本地 MCP 放进不允许任何网络连接的沙盒，所以 Sandhill 的工具改为通过本机回环 HTTP（带一次性令牌）提供，详见 `docs/design.md`。

Huan 已定（2026-11-11）：
- 只做聊天模式，命令行模式先不做。
- 默认让 OpenScience 用 Sandhill 的内核运行代码。

## 已查明的事实（本机 openscience 2.0.153）

- 它有 `openscience acp` 命令：用通用的“Agent Client Protocol”（ACP）和编辑器对话，Zed、JetBrains 也用这个协议。
- 我只发了一条握手消息，没有开对话，也没有花额度。它的回复说明它支持：
  - 接着以前的对话继续、列出对话；
  - 接收外部工具服务（MCP）；
  - 消息里带图片；
  - 不需要通过这个接口另外登录，直接用你本机已有的登录和 API key。
- 它运行代码用的两个自带工具叫 `python` 和 `r`。它的文档说明：被设为“禁止”的工具，助手根本看不到。
- Sandhill 可以只对自己启动的那个 OpenScience 加设置，不改你的配置文件。实测这些设置会和你原有的设置合并，不会覆盖。

## 做法

1. **通用的 ACP 聊天转接**
   - 后台程序里新写一个按 ACP 对话的转接，和现在的 Codex 转接一样，跑在 Sandhill 保管的终端里，所以关掉 App 后也能继续。
   - 设计文档里早就计划过“用 ACP 接其他助手”，这次先接 OpenScience。以后接 omp、Gemini 等，只需各加一项配置。
2. **启动 OpenScience 时**
   - 在项目文件夹里运行 `openscience acp`，并只对这一个进程加三项设置：
     - 禁止它自带的 `python`、`r` 工具；
     - 告诉它把 Sandhill 的工具接进来；
     - 附一份 Sandhill 写的简短说明，例如：分析代码用 Sandhill 的“运行代码”工具，在用户当前的会话里跑；图和变量留在 Sandhill。
   - 你自己的 OpenScience 设置、技能、MCP、数据库连接全部照常。
3. **聊天里显示**
   - 回答文字、思考过程、每一步工具调用（包括调用 Sandhill 运行代码）、计划，都按现有聊天的样式显示。
   - 它的“是否允许”请求变成聊天里的批准卡片，选项和它自己的一致：本次、本对话、本项目、拒绝。
4. **权限各管各的**
   - OpenScience 自己的工具（读写文件、网络、计算任务）按它的批准规则。
   - 通过 Sandhill 工具运行的代码按 Sandhill 的模式。例如在 Ask（只读）模式下，Sandhill 不让它运行代码，并告诉它原因。
5. **接着对话、重新连接**
   - 重新打开项目或重连后，用 ACP 的“载入对话”把历史恢复到聊天里，用的是它自己的记录。
6. **模型**
   - 模型下拉框列出它已配置好的模型。ACP 有没有提供列表和切换模型的功能，要在动手时实测；没有的话，就用它的 `openscience models` 命令读出模型列表，选好后在开始对话时传给它。
   - 它没有订阅额度，所以状态栏不显示它的额度。
7. **远程服务器**
   - 服务器上要你自己安装并登录 openscience，Sandhill 不替你安装，和 Claude Code、Codex 一样。
   - 没装时，模型菜单里它显示为“未安装”。
8. **Notebook 的 AI 操作**
   - Explain/Improve 等 AI 操作也可以选 OpenScience，因为它们走的是同一个聊天。

## 风险和限制

- 它的部分技能是按自带的 `python` 工具写的。自带工具被禁止后，这些技能会改用 Sandhill 的工具，或者用命令行跑脚本。用命令行跑的脚本不在 Sandhill 的会话里。
- 它的说明和技能只是“指导”，不能百分之百保证它每次都用 Sandhill 的内核。
- 它更新很快，要固定一个已测试的版本。版本不一致时，在模型菜单里提示一下。

## 需要你决定

1. **图标：** 它的标志用不用、在哪里使用，需要单独确认授权。在确认之前，先用一个通用图标，和 omp 的处理方式一样。
2. **真机测试：** 自动测试用模拟的 ACP 程序。另外我想用你本机真的 OpenScience 做一次完整试用：发一两条短消息，让它在 Sandhill 内核里跑一行代码。这会用掉你一点点模型额度，需要你同意。
