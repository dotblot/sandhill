| `file.bibliography` | other | `.bib` |
| `file.file` | other | `.txt` |

Compressed files keep the icon of what is inside: `.gz`, `.bgz`, `.bz2`, `.xz`, `.zst` are stripped first, so `reads.fastq.gz` is a FASTQ and `matrix.mtx.gz` a sparse matrix.

## Folders

| Icon | Names |
|---|---|
| `folder.project` | the project root |
| `folder.data` | `data`, `raw`, `input` |
| `folder.results` | `results`, `output`, `out` |
| `folder.figures` | `figures`, `figs`, `plots` |
| `folder.tests` | `tests`, `test` |
| `folder.sandhill` | `.sandhill` |
| `folder.notebooks` | `notebooks`, `analysis` |
| `folder.scripts` | `scripts`, `r`, `src`, `bin` |
| `folder.cache` | `cache`, `.cache`, `tmp`, `work` |
| `folder.other` | `.github` |

A folder's icon only changes how it looks. Sandhill does not treat files differently because of the folder they are in.
