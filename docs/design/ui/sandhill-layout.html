What to react to (hover a note to find it in the window)

  1. Positron's layout, keptEditor in the middle, Variables and Plots on the right, Console below. Every pane folds away from the title bar buttons.
  2. Outputs live in the document, hidden by defaultEach chunk keeps its output right under it, folded to one line. Click a line to show that output, or use Show outputs in the document bar for all of them. Hidden plots and tables are not drawn at all.
  3. Stale outputs stay visible, greyedThe markers chunk was edited after it ran. Its folded line says "stale"; shown, the old output is faded with a Run button. Try it.
  4. One kernel bar per documentR and Python each get a session picker, interrupt and restart. Sessions keep running on gpu01 when the app closes.
  5. One tab per agent sessionThe Agents column starts empty. Each new session picks one model (Claude Code, Codex or omp) and the documents it works on. Claude Code and Codex stay their real terminals; omp is a chat.
  6. Context bar and session controlsA thin context bar above the input shows how full the session is, with ticks where compacting is suggested and where auto-compact starts; click it for the breakdown and to compact. Below the input, one button holds the model and thinking effort (pick a model, drag the effort slider), and another the permissions.
  7. Zoom and export plotsThe magnifier in the Plots pane opens the plot large. Set its size (or pick a preset), then copy it or save it as PNG, PDF or SVG; the kernel re-draws it at that size.
  8. Free memory from VariablesTick variables in the Variables pane, see how much memory they hold, and delete them; Sandhill runs rm() and gc() in that session.
  9. Data Explorer opens as an editor tabClick the table icon next to a data frame, or "Open in Data Explorer" under a table output. Sorting and filtering run in the kernel.
  10. Toolbar over the left paneLeft pane, right pane and agents toggles sit next to the window buttons, followed by search (files, symbols, commands) and the menu (connect, open or create a project, recent projects, settings). The panes run up to the top of the window; with the left pane hidden, the first pane's tabs start after the toolbar.
  11. Status bar shows plan usageClaude Code and Codex, shown by their provider icons, each show 5-hour and weekly usage and the time left until each resets. Click one for details and to spend a banked reset. Also the daemon link, kernels, jobs, and a note when a session waits for you.
  12. Floating glass panesEditor, console, Variables, Plots and agents are rounded, translucent cards floating on the window background, in the style of macOS Liquid Glass. The title bar, rail, the rail's side pane and the status bar sit directly on the background.
  13. Git graphThe Git tab, next to Variables, Help and Packages, shows branches, a commit graph with author avatars (people, Claude Code, Codex) and the message, then staged and unstaged files with Write it, which asks an agent for a commit message.
  14. Minimize and maximizeEvery pane has minimize and maximize buttons at the right of its tab bar. Minimized, only the tabs show; maximized, the pane fills the window until you restore it.
  15. Resize and move panesDrag the thin gap between two panes to resize them; an orange line shows when you are on it. Drag Console, Variables or Plots by its tab strip to move it under the editor or into the right column.
  16. Coloured file and folder iconsFlat icons in a muted palette: Quarto, R, notebooks, Python, Markdown, lock files and data each get a shape and colour, and folders show what they hold.
  17. Local and server tabsThe left pane has a tab per machine. Each shows that machine's project files, its running kernels (shut one down from its row) and CPU, memory, GPU and disk use; click a resource for details.
  18. Help search by packageIn the Help tab, search a function or topic. Name a package to search only that package, or leave it empty to search all of them.
  19. Right-click for sourceRight-click a function or package name in code, Help or Variables: open its help, view its source in a read-only tab, or open the whole package.
